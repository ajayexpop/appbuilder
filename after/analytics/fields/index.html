2EventFiltersselect
All events
After “All events” comes each of the app's events that had activity in the chosen period, busiest first, named by its title (or “Event [id]” when the title is unknown), with “[n] people” under it. A chosen event that has no activity in the period is still listed, as “Event [id]”.
All eventsThe “[n] people” beside each event counts people over the whole app for that event and ignores Platform and User type. Event titles come from your ExpoPlatform admin's event list, in English; a title changed there can take up to ten minutes to show here. When that list cannot be read, the event's id is shown.appNot saved: kept in the page's address, so it stays when you reload the page; the numbers are read again.
3PeriodFiltersselect
7d 14d 30d 90d
30d (the last 30 days, today included)Each preset is the last 7, 14, 30 or 90 days ending today. Days are whole UTC days, and today is the UTC day. A preset is highlighted when the period ends today and has its length.appNot saved: kept in the page's address, unless it is the default, so it stays when you reload the page; the numbers are read again.
4Custom periodFiltersdateThe current periodA period is at most 92 days, from and to included. On Apply the two days are put in order, the end is cut to today and, if the range is wider than 92 days, its end is kept and its start moved up. Cancel or closing the calendar drops the choice. The calendar is shown in English (en-US) dates.appNot saved: on “Apply” only, the period is kept in the page's address, so it stays when you reload the page, and the numbers are read again.

Buttons and controls

ButtonWhat it does
How to readAnalyticsOpens the slide-out Analytics guide on the part for the tab you are looking at (Basics when there is none).
ExportAnalyticsOpens the export dialog. The click itself sends nothing; the file is only made from the dialog. While an export is being made the button reads “Preparing PDF…” or “Preparing CSV…” with a spinner; when it is ready it reads “PDF ready” or “CSV ready” with a tick. Not shown on the Devices tab.
RefreshAnalyticsReads the open tab again under the current filters, even when it already has those numbers. The button spins while it reads. Other tabs keep what they showed. Not shown in the header of the Devices tab, which has its own Refresh.
Reset filtersFiltersClears the event, platform and user type and sets the last 30 days. Shown only when a filter differs from its default: an event, a platform or a user type is set, or the period is not the last 30 days ending today. The numbers are read again.
Event, the period buttons, the calendar's Apply, Platform, User typeFiltersEach change applies at once: the open tab is read again under the new filters, and the choice is kept in the page's address.
opening the Event list or the calendarFiltersOnly opens the list or the calendar; nothing is read until a choice is made (an event, or Apply in the calendar).
Overview / Audience / Engagement / Content / Networking / Promotion / Performance / TechTabs and tab statesShows that dashboard tab with the same filters; if it was not read yet under these filters, it is read now.
DevicesTabs and tab statesShows the Devices tab. The first time, it reads the install summary and the first page of devices; after that it shows what it already has.
Try againTabs and tab statesReads the failed tab again.
Clear filtersTabs and tab statesDrops the event, platform and user-type filters and keeps the period; the tab is read again.
Show the last 90 daysTabs and tab statesSets the period to the last 90 days ending today; the tab is read again.
IP geolocation by DB-IPAudienceOpens the location data provider's website in a new tab (its licence asks for this credit).
Show all [n] / Show fewerAudienceShows the rest of a table's rows (tables show 8 rows first), or folds them again. Nothing is saved.
Show all [n] / Show fewerEngagementShows the rest of a table's rows, or folds them again. Nothing is saved.
Exhibitors · [n] | Products · [n] | Sessions · [n] | Speakers · [n] | Brands · [n]ContentSwitches the Top table to that kind of item. Nothing is saved.
Show all [n] / Show fewerContentShows the rest of a table's rows, or folds them again. Nothing is saved.
Show all [n] / Show fewerPromotionShows the rest of a table's rows, or folds them again. Nothing is saved.
Show all [n] / Show fewerPerformanceShows the rest of a table's rows, or folds them again. Nothing is saved.
Show all [n] / Show fewerTechShows the rest of a table's rows, or folds them again. Nothing is saved.
How to readDevicesOpens the Analytics guide on its Devices part.
RefreshDevicesReads the install summary and the first page of devices again, under the current device filters.
Show devicesDevicesNarrows the device list to that version and platform, reads it, and scrolls to it.
SearchDevicesApplies the typed search to the device list (also on Enter).
ClearDevicesResets every device filter and the search. Shown only when a filter or typed search differs from the defaults.
Platform / App version / Signed inDevicesEach choice applies at once and reads the device list again.
Show more ([n] shown)DevicesLoads the next page of devices (50 at a time). Shown when more exist.
a device rowDevicesOpens that phone's side panel and reads its details.
a phone under 'Same person, other phones'DevicesOpens that other phone in the side panel.
Try againDevicesReads the device list again after it failed.
IP geolocation by DB-IPDevicesOpens the location data provider's website in a new tab.
Format, section boxes, Select all / Clear allExport analyticsChoices for the file, kept in the dialog. Nothing is sent until “Make the PDF” / “Make the CSV files”.
Make the PDFExport analyticsStarts making the file. Shown as “Make the CSV files” when CSV is chosen; disabled with no section ticked.
Download PDFExport analyticsDownloads the finished file (“Download ZIP” for CSV).
Make anotherExport analyticsGoes back to choosing, in the dialog. Only the dialog changes; nothing is sent.
Try againExport analyticsGoes back to choosing after a failed or expired export, in the dialog. Only the dialog changes; nothing is sent.
CancelExport analyticsCloses the dialog (“Close” once an export has started). The export keeps being made.
a part buttonAnalytics guideShows that part of the guide in the panel.
