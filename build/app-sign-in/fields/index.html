Buttons and controls

ButtonWhat it does
EventEvent and language barChooses which event's sign-in and registration settings are shown and edited. It lists the app's events and shows only when the app has events. Picking one reloads the section's settings for that event; unsaved edits are dropped without asking. Each event's settings start from the old App Builder's values, copied once.
Language of the textsEvent and language barChooses which language's texts are shown and edited; it starts on English. It shows only when the app has more than one language. Switching reloads the section's settings in that language; unsaved edits are dropped without asking.
Save changesSave barSaves only the fields that changed, for this event and language, in App Studio; when “Native registration form” changed, it first saves that for the whole app. Nothing is sent to the old App Builder or the old apps. Disabled until something changes.
