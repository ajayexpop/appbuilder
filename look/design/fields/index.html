Buttons and controls

ButtonWhat it does
Light / DarkEvent pickerChooses which scheme's colours and fonts the block shows. It is the same switch state as the Colours block and the phone preview's theme, so the preview turns light or dark with it. Nothing is sent.
Light / DarkColoursSwitches the colour fields between the light set and the dark set. The same state drives the phone preview's theme, so the preview turns light or dark too. Nothing is sent.
Start from a palette: Aurora, Midnight, EditorialColoursFills all 21 colour fields of this event, in the scheme you are on, with the palette's colours. It does not touch the sponsor bar, fonts or pictures. It is a one-time fill you can edit, not a stored layer. Nothing is sent until Save.
Use [hex]ColoursSets Primary (in the current scheme) to the darker colour App Studio computed so that the Tertiary text on it reaches 4.5:1. Nothing is sent until Save.
Use default ([hex])BrandClears your value so the field goes back to the event's own colour. The phone preview keeps showing the old colour until you save.
Pick [label]BrandThe colour square at the start of the field: opens a colour picker (a colour area, an eye dropper and a hue slider) for the field.
Upload / ReplacePicturesOpens the file chooser (PNG or JPEG), then the crop dialog. Choosing the file sends nothing.
UploadPicturesThe button in the crop dialog, headed “Crop the” and the picture's name (for example “Crop the login logo”). Uploads the cropped picture and stores it for this app at once, before Save; the field then holds the stored picture.
Or paste a link to a picturePicturesA link field. When you leave it or press Enter, App Studio fetches the picture from a link that starts with https:// and stores it for this app at once.
Use default / Show the defaultPicturesClears your picture (or your “No picture”) so the event's current picture applies again. The preview keeps the old picture until you save.
No picturePicturesSets the field to show no picture at all, even if the event has one. Nothing is sent until Save.
Open the picturePicturesThe small picture in the field: opens the stored picture in a new tab.
Save changesSave barSaves the whole draft of this page and of “Name, icon & splash” together: every event's colours (light, and dark when any is set), sponsor bar, fonts, pictures and missing-picture choice, the event picker palette (multi-event apps) and the app's icon, name and splash. The button is always enabled; it shows a spinner while saving.
Light theme / Dark themePhone previewIcon buttons beside the phone preview (each name shows when you point at it). They switch the preview's theme and, with it, the form's Light/Dark switch.
iPhone 16 Pro / iPhone (notch) / Pixel 9 ProPhone previewIcon buttons beside the phone preview: they change the phone's frame. Not saved: they only change the preview.
BackPhone previewGoes back inside the live preview app.
Restart app (replay splash)Phone previewRestarts the preview app, so the splash plays again.
PreviewPhone previewOn narrower windows the phone is replaced by a floating “Preview” button that opens it as a sheet (“App preview”, “Close”).
Home / My Badge / Boot flowPhone previewThe switch beside the small “Preview” label, below the form: where the preview starts, on the home, on My Badge, or walking through the splash, login and choose event. Not saved: it only changes the preview.
Signed-in preview / Guest previewPhone previewStarts the preview as a signed-in person or as a guest (only when the preview starts on Home). Not saved: it only changes the preview.
