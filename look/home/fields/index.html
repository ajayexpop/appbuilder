Buttons and controls

ButtonWhat it does
Show it hereYour event's original home pageCard “Show it here, linked”: puts an “Original home page” block at the top of the blocks and opens it. The page stays where it is edited today, the home shows it, and it leaves the menu. Draft only.
Take it off the homeYour event's original home pageShown once the linked block is on the home: removes it, and the page goes back to the menu. Draft only.
Copy it hereYour event's original home pageCard “Copy it here to edit”: adds a Custom HTML block at the top of the blocks, holding the page in every language of the event, yours to edit. The original no longer reaches the copy; its menu entry stays. The copy is in the draft until saved.
EN / DE / FR / ES / IT / RUHeaderLanguage buttons above a text: pick which language's text you are editing.
Use default ([default])HeaderUnder a field with your value: clears it, so the default applies.
Upload / Replace / Use default / No picture / Or paste a link to a pictureHeader pictureThe picture field controls, as on Colours & fonts: choosing a file opens the crop dialog; its “Upload”, or a pasted https:// link, stores the picture for the app at once.
Upload MP4 / ReplaceHeader pictureVideo field: uploads the chosen MP4 at once, then a still picture taken from its first frame.
Use the defaults (56 px, left, 16 px above, 14 px under)Header pictureShown once a logo setting is changed: puts position, size and spacing back. Draft only.
Top bar colour fading outHeader pictureReplaces the gradient with two colours: the top bar colour, solid at the top, fading to clear at the bottom. Draft only.
Add a colourHeader pictureAdds a gradient colour; hidden at 5. Draft only.
Remove this colourHeader pictureTooltip of a gradient colour's trash button: removes that colour. Draft only.
Use defaultHeader pictureBeside a slider that has a value: clears it so the default applies.
Move [name]BlocksDrag handle: reorders the block. Draft only.
[block name] / Edit [name] / Close [name]BlocksThe block's name or its chevron opens or closes its settings.
Remove [name]BlocksTrash button: takes the block off the home at once, without asking. Draft only, until saved.
Add a block: [block name]BlocksTray of the blocks this home does not have yet; blocks that may appear more than once (Button row, Tile grid, Image row, Section heading, Custom HTML, Hero banner) stay offered. Adds the block at the end, switched on, with its default audience, and opens it. “Original home page” is offered only when the event has one. Draft only.
Search by name, or type an idLinks, icons and styling inside a blockItem search for matching exhibitors, sessions, products or people. It searches the event as a guest, someone who is not signed in, so a person only signed-in people can see is not offered.
Use this stand / RemoveLinks, icons and styling inside a blockSets a stand link from the typed number (placeholder “A12”), or removes the item link. Draft only.
Add a counterStats at a glanceAdds a counter (hidden at 3). Draft only.
Add a buttonButton rowAdds a button (hidden at 2). Draft only.
Add a tileTile gridAdds a tile (hidden at 8). Draft only.
Add a pictureImage rowAdds a picture slot (hidden at 2). Draft only.
Open full-screen editorCustom HTMLOpens the HTML (per language) and the CSS side by side. Draft only.
Add a suggestion / Add a page / Add a factAI SynapsiumAdds a row to a capped list (hidden at the cap). Draft only.
Default / On / OffAI SynapsiumEach switch in “What it can do” and “What it can read about the person”. Draft only.
Prepare againPreparationShows “Try again” after a failure. Prepares the assistant for this event again, sending only what changed. It works only while the saved home offers the assistant: the AI Synapsium block switched on, or “AI assistant” as the “Button in the top right”.
Send everything againPreparationSends the whole event to the assistant again, not only what changed. Meanwhile “Preparation” shows “Sending everything again”, and the assistant keeps answering from what it has until this finishes.
Upload / Replace / Use default / Or paste a link to a pictureBadge picturesAs on the other picture fields: the crop dialog's “Upload”, or a pasted https:// link, stores the picture for the app at once.
Restore the default homeStart overOpens the inline confirmation; nothing is sent. Disabled while a save is running.
Restore the defaultStart overSaves at once: clears this event's own layout. The event then shows the app-wide home if one is set, else the built-in default. Badge pictures and the Designed home screen switch are not touched.
Keep my homeStart overCloses the confirmation without changing anything.
Save home screenSave barSaves the layout of every event you edited since the last save (whole layouts), the selected event's badge pictures if they changed, and the Designed home screen switch if it changed, all at once. It does not save Colours & fonts, which has its own “Save changes”. Always enabled. After saving, App Studio prepares the AI assistant for each event whose saved home offers it (the AI Synapsium block switched on, or “AI assistant” as the “Button in the top right”) and that is new, changed or not yet ready; “Preparation” in the block shows its state.
Light theme / Dark theme / Preview device / Back / Restart app (replay splash)Phone previewThe buttons beside the phone preview, as on Colours & fonts: theme, phone frame (iPhone 16 Pro, iPhone (notch), Pixel 9 Pro), back inside the app, restart. Not saved: they only change the preview.
Home / My Badge / Boot flowPhone previewThe switch beside the small “Preview” label, below the form: where the preview starts, on the home, on My Badge, or walking through the splash, login and choose event. Not saved: it only changes the preview.
Signed-in preview / Guest previewPhone previewShows the home as a signed-in person or as a guest (only when the preview starts on Home). Not saved: it only changes the preview.
