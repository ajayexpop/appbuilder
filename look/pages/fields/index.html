Buttons and controls

ButtonWhat it does
Event picker (shows the chosen event)Your pagesShown only when the app has more than one event (the name is the picker's accessible name; it shows the chosen event's title). Picks the event whose pages you see and write; Menu & content and the preview follow it. Only reads; changes nothing.
Return to itYour pagesShown with the unsaved-page banner. Picks that page's event and opens the unsaved page again in the editor. Changes nothing.
New pageYour pagesOpens or closes a panel with two choices: “Write a page” and “Add a built-in screen”. Nothing is sent.
Write a pageYour pagesOpens the editor on a new page for the selected event. If another page of this event still has unsaved changes, that page opens instead, with a note (one unsaved page per event). Nothing is sent until “Save page”.
Add a built-in screenYour pagesShows the screen picker (see “Add a built-in screen” below). Opening it sends nothing.
Menu sectionAdd a built-in screenChooses the menu section to add a screen to: Event (the default), My company (team), My account or My company (exhibitor admins). The buttons below list the built-in screens that section can hold and does not have yet. Nothing is sent.
[screen name]Add a built-in screenOne button per screen, named after the screen. Adds that screen to the end of the chosen section of this event's menu at once, without a save step; installed apps show it after their next refresh, as the message says. Unsaved changes in the menu stay unsaved. Disabled while the menu is saving.
Add to menuEverything in your appShown on a page of yours that is not in the menu. Adds the page to the end of the Event section of this event's menu at once.
Show in the previewEverything in your appThe eye on a page of yours or on an Event page: opens that page in the phone preview. Only the preview changes; nothing is sent.
Delete pageEverything in your appThe trash on a page of yours: opens the confirmation “Delete [title]?”. Nothing is deleted yet.
Delete pageEverything in your appThe red button in the confirmation: deletes the page for good and takes it out of the event's menu. Installed apps stop offering it on their next refresh, as the message says.
CancelEverything in your appCloses the confirmation. Nothing is sent.
EditEverything in your appOn a page of yours: opens it in the editor. If another page of this event still has unsaved changes, that page opens instead, with a note. Nothing is sent.
EditEverything in your appOn an Event page (made before App Studio): opens Menu & content for this event with that page open; its tabs, text and HTML are edited there.
[n] linksLinks for your own HTMLShows the in-app addresses of this event's screens and pages (the button then reads “Hide”), with a line on using one as a link's address in your own HTML, and an example. Not saved: it only changes what this page shows.
CopyLinks for your own HTMLCopies that address to the clipboard; the tooltip then reads “Copied”. Nothing is saved.
All pagesPageCloses the editor and goes back to the list. A page with unsaved changes is kept as a draft (the list then offers “Return to it”); a page without changes is closed. Nothing is sent.
Language you are writing inPageButtons EN, DE, FR, ES, IT, RU. Picks the language you are writing in: the title, the tab names, the text and the preview follow it. Not saved by itself.
[tab name]TabsEach tab is a chip with its name and its number of blocks; clicking one selects it, so its settings and blocks show below.
Move [tab name]TabsThe grip on a tab chip (only with more than one tab): drag to change the order of the tabs.
Add a tabTabsAdds an empty tab at the end and selects it. Shown while the page has fewer than 10 tabs.
Remove tabTabsOnly with more than one tab. Removes the selected tab at once when it has no blocks; otherwise asks first. Removing a tab removes its blocks. Saved by “Save page”.
UploadTabsOf “Background picture (9:16)”: opens the file chooser, then a crop dialog at 9:16. Nothing is sent until “Upload” in the dialog.
UploadTabsIn the crop dialog: uploads the cropped picture at once.
Or paste a link to a pictureTabsA field for a picture's https:// address: when you leave the field or press Enter, App Studio fetches the picture and keeps a copy for this app.
Use defaultTabsShown when a picture is set: takes it off the tab in the unsaved page.
TextBlocksIn “Add a block” (and likewise each block button): adds the block to the end of the selected tab. Each button's tooltip describes the block.
Move [label]BlocksThe grip on a block row: drag to change the order of the blocks on this tab.
Edit [label]BlocksThe chevron (or the block's name) opens the block's settings; it then reads “Close [label]”. Only the view changes.
Remove [label]BlocksThe trash on a block row: removes the block from the unsaved page at once, without asking.
Text formattingTextThe toolbar (its accessible name): Heading 1 to 3, Bold, Italic, Underline, Strikethrough, Bulleted list, Numbered list, Quote, Align left, Align centre, Align right and Justify format the text.
LinkTextOpens the link bar for the selected text: “Web address” (type it, then “Apply”; a bare domain gets https://) or “Screen in the app” (choose from “A screen or page...”; the link is set at once).
Search by name, or type an idTextShown after choosing a screen that lists items (such as exhibitors or sessions): narrows the link to one item. It searches the event's items when it appears and as you type. Only reads.
Remove linkTextTakes the link off and closes the link bar.
PictureTextOpens the file chooser (PNG or JPEG). The chosen picture is uploaded at once and placed in the text.
Picture alignmentTextWith a picture selected: Left, Centre or Right, and the “Width” slider (10 to 100 %, in steps of 5) resize and place it.
Open full-screen editorYour own HTMLOpens the HTML and the CSS side by side with a live phone-width preview. Nothing is saved until you press “Save page”.
Language of the markupYour own HTMLIn the full-screen editor, with more than one language: switches which language's HTML you edit (a dot marks languages that have markup). Not saved: it only changes what this page shows.
DoneYour own HTMLCloses the full-screen editor (Esc too); what you typed stays in the block, unsaved until “Save page”.
Save pageSave barA new page: stores it for this event and, with “Add to the menu when saved” on, adds it to the end of the Event section. A saved page: stores the changes; refused if someone else saved the page since you opened it. Off while problems are listed. The page stays open after saving.
DiscardSave barWith unsaved changes it asks first; without, it closes the page at once. Nothing is sent.
Discard pageSave barIn the confirmation: throws away the unsaved page in this browser and closes it. Nothing is sent; a saved version stays as it was.
Delete pageSave barShown for a saved page: opens the confirmation “Delete this page?”. Nothing is deleted yet.
Delete pageSave barIn the confirmation: deletes the page for good and takes it out of the event's menu; the editor closes.
Light themePhone previewWith “Dark theme”: shows the app in the preview in light or dark. Separate from App Studio's own theme.
Phone model buttons beside the previewPhone previewIcon buttons that change the phone model drawn around the preview.
BackPhone previewGoes back inside the app in the preview.
Restart app (replay splash)Phone previewStarts the app in the preview again.
PreviewPhone previewUnder the page: “Home”, “My Badge” or “Boot flow” chooses where the preview starts. Only the preview changes.
Signed-in preview or Guest previewPhone previewWith “Home”: “Signed-in preview” or “Guest preview” shows the app as a signed-in person or as a guest. Only the preview changes.
