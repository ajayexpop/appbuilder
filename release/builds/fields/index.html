Buttons and controls

ButtonWhat it does
Build & testBuild & testThe sidebar entry under “Release” (shown as “RELEASE”). Opens this section.
Build & testBuild & testThe blue button with a package icon in the top bar of every page of an app, beside “Guide” and the theme switch. It is a link that opens this section; it starts no build by itself.
Build for [platform]BuildsOne button per platform: “Build for iOS” and “Build for Android”. Opens a dialog for that platform; nothing starts until “Start the build”. Greyed out while a build of that platform is starting or running (it then reads “iOS build running” or “Android build running”), and while ExpoPlatform has not set the app up in the stores; the reason then shows when you point at the button or reach it with the keyboard. An iOS and an Android build can run at the same time.
Show older buildsBuildsThe list shows the 5 newest builds first; each press shows 10 more. It only changes what this page shows.
Download [file type]One build in the list: its status, file and signing, progress, download and install linkOn a finished build with a file: opens the file in a new tab. On screen “Download AAB”, “Download APK”, “Download IPA” or “Download XCARCHIVE” (the file type in capitals), or “Download” alone when the type is unknown. Each download link works for 5 minutes after the page last loaded the list of builds.
StopOne build in the list: its status, file and signing, progress, download and install linkShown while a build is queued or building. Stops it at once, without asking first: the message “Build stopped” appears, and the card shows “Failed”, with “Cancelled by admin” in its details. If the build finished in the meantime, it stays finished and the message says so.
DetailsOne build in the list: its status, file and signing, progress, download and install linkOpens the build's details (the button then reads “Less” and closes them). On a “Building” or “Ready” build, the details also show what changed since the previous build: App Studio writes that list once for each pair of builds, from the changes to the app's code, with an AI model, and keeps it. On a queued or failed build it only opens the details.
Open linkOne build in the list: its status, file and signing, progress, download and install linkOpens the build's install page in a new tab. The card shows “Install link” only for a build that has an install page.
Copy linkOne build in the list: its status, file and signing, progress, download and install linkCopies the install link; the button then reads “Copied”. Nothing is saved or sent.
A QR code of the install linkOne build in the list: its status, file and signing, progress, download and install linkScanned with a phone's camera, it opens the install page on the phone.
CopyWhat changed since the previous buildCopies the store text (the “What's new” lines); the button then reads “Copied”. Nothing is saved or sent.
App Bundle (AAB)Build for [platform]Chooses the App Bundle for this Android build. Nothing is sent until “Start the build”.
APKBuild for [platform]Chooses an installable APK for this Android build. Nothing is sent until “Start the build”.
Also prepare for store screenshotsBuild for [platform]Ticks or unticks the screenshot preparation. Nothing is sent until “Start the build”.
CancelBuild for [platform]Closes the dialog; nothing is sent. Greyed out, and the dialog cannot be closed, while the build is being started.
Start the buildBuild for [platform]Starts the build, always from the app code ExpoPlatform deploys; it is refused until ExpoPlatform has set the app up in the stores. The message “iOS build started” or “Android build started” appears, and the build appears in the list as “Queued”. It takes the next build number of your app, for good.
Send to testersSend to testersOpens the “Send to testers” dialog. Nothing is sent until its “Send”.
TestFlightSend to testersChooses TestFlight (iOS). Nothing is sent until “Send”.
Google Play internal testingSend to testersChooses Google Play internal testing (Android). Nothing is sent until “Send”.
BuildSend to testersPicks the build to send. Nothing is sent until “Send”. It cannot be changed while sending, or when an earlier send is continued.
ContinueSend to testersGoes to the next step; greyed out until a channel that can be used is chosen. Nothing is sent.
BackSend to testersGoes back one step; greyed out while sending. Nothing is sent.
CancelSend to testersOn step 1: closes the dialog; nothing is sent.
SendSend to testersGreyed out until a channel and a build are chosen and, for TestFlight, there is at least one tester. Then, without asking again, it prepares a test release of the chosen build (unless an earlier unfinished send is continued), adds the addresses you typed to the TestFlight group or the Google Play internal testing track, and sends the build to TestFlight or Google Play; the send shows as “Uploading” while it goes. When a demo account for the store reviewers is saved, a TestFlight send first checks its demo event, unless that check is switched off for your app. The dialog cannot be closed while it sends; after a failure, “Send” again continues the same release. No ExpoPlatform approval is needed.
Try againTestersAfter the testers could not be loaded: loads them again from App Store Connect and Google Play. Nothing is changed.
AddTestFlight (iOS)Adds the new addresses to TestFlight at once (it reads “Add [n]” for several); greyed out until a new address fits the limit; the box empties on success. Each address is sent to App Store Connect.
The bin icon on each rowTestFlight (iOS)A bin icon on each row. Removes that tester at once, without asking first, from the TestFlight group shown here only, not from the app's other TestFlight groups; other remove buttons wait meanwhile. It has no visible text; screen readers announce it with the address.
Copy linkTestFlight (iOS)Copies the public TestFlight link; it then reads “Copied”. Nothing is saved or sent.
A QR code of the public TestFlight linkTestFlight (iOS)Scanned with an iPhone's camera, it opens the public TestFlight link.
AddGoogle Play internal testing (Android)Adds the new Google Group addresses to the Google Play internal testing track at once (it reads “Add [n]” for several); greyed out until a new address is typed.
The bin icon on each rowGoogle Play internal testing (Android)A bin icon on each row. Removes that Google Group from the track at once, without asking first. It has no visible text; screen readers announce it with the address.
